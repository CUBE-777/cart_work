مجلد صور المشاريع / Project images
------------------------------------
لكل مشروع مجلد باسم id المشروع (نفس القيمة في data.js):

  assets/portfolio/اسم-المشروع/
      cover.webp          صورة الغلاف
      gallery/            صور المعرض: 01.webp, 02.webp ...
      before-after/       (اختياري) before.webp و after.webp

يفضَّل صيغة WebP. الغلاف 1200x900، وصور المعرض بعرض 1600px كحد أقصى.
